A seamless level loadig prototype with saving & loading using JSON, and a simple achievements system.

Made with Godot version 4.5

If you download the project to test it you need to type "1996" into the vending machine before a new level loads behind the vending machine.

**NOTE**
Level loading is only seamless after the shaders have been compiled, so the game will freeze for a brief moment when loading a level for the first time.
